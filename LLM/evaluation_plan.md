# 청년정책 RAG 시스템 성능 평가 기획서

## 1. 개요

### 1.1 목적
- 청년정책 RAG 시스템의 성능을 다양한 LLM 모델로 평가
- 각 모델별 응답 품질과 처리 시간 분석
- 최적의 모델 선택을 위한 정량적 데이터 수집

### 1.2 평가 대상 모델
1. **GPT-4o** (OpenAI)
2. **GPT-4.1** (OpenAI) 
3. **Gemini-2.5-Flash** (Google)

### 1.3 평가 데이터셋
- **파일**: `testset.csv`
- **질문 수**: 20개
- **질문 유형**: 청년정책 관련 질문, 일반 질문 포함

## 2. 평가 지표

### 2.1 성능 지표
- **응답 시간 (Response Time)**: 각 질문에 대한 답변 생성 시간 (초)
- **응답 품질 (Response Quality)**: O3-mini 모델을 활용한 5점 척도 평가

### 2.2 평가 기준 (5점 척도)
- **5점**: 매우 우수 - 질문에 완벽히 부합하는 정확하고 유용한 답변
- **4점**: 우수 - 질문에 잘 부합하며 대부분 정확한 답변
- **3점**: 보통 - 질문에 부분적으로 부합하는 답변
- **2점**: 미흡 - 질문과 관련성이 낮거나 부정확한 답변
- **1점**: 매우 미흡 - 질문과 무관하거나 잘못된 답변

## 3. 평가 프로세스

### 3.1 자동화된 평가 파이프라인
```
1. 테스트 데이터 로드 (testset.csv)
2. 각 모델별 답변 생성 및 시간 측정
3. O3-mini를 활용한 답변 품질 평가
4. 결과 저장 및 분석 리포트 생성
```

### 3.2 평가 실행 단계
1. **데이터 전처리**: testset.csv 파일 로드 및 검증
2. **모델별 실행**: 
   - GPT-4o로 모든 질문 처리
   - GPT-4.1로 모든 질문 처리
   - Gemini-2.5-Flash로 모든 질문 처리
3. **시간 측정**: 각 질문별 응답 생성 시간 기록
4. **품질 평가**: O3-mini를 활용한 자동 평가
5. **결과 저장**: CSV 형태로 결과 저장

## 4. 결과물

### 4.1 생성될 파일
- `evaluation_results_{timestamp}.csv`: 전체 평가 결과
- `model_comparison_report_{timestamp}.json`: 모델별 비교 리포트
- `evaluation_summary_{timestamp}.md`: 평가 요약 보고서

### 4.2 결과 데이터 구조
```csv
query_id,query,model,response,response_time,quality_score,evaluation_details
1,"25세 대학생을 위한 전세자금대출이 있나요?",gpt-4o,"...",2.34,4,"정확한 정책 정보 제공"
1,"25세 대학생을 위한 전세자금대출이 있나요?",gpt-4.1,"...",1.89,5,"매우 상세한 답변"
1,"25세 대학생을 위한 전세자금대출이 있나요?",gemini-2.5-flash,"...",1.23,3,"일반적인 답변"
```

## 5. 기술적 구현

### 5.1 주요 컴포넌트
1. **EvaluationManager**: 전체 평가 프로세스 관리
2. **ModelRunner**: 각 모델별 실행 및 시간 측정
3. **QualityEvaluator**: O3-mini를 활용한 품질 평가
4. **ResultsCollector**: 결과 수집 및 저장

### 5.2 의존성 라이브러리
- `langchain-openai`: OpenAI 모델 연동
- `langchain-google-genai`: Gemini 모델 연동
- `pandas`: 데이터 처리
- `json`: 결과 저장
- `time`: 성능 측정
