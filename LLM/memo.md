# V1
그냥 RAG 코드
## 문제점
데이터 총 갯수가 몇개인지 파악못함

# V2
## 특징
데이터 총 갯수를 묻는 질문이 들어왔을 때 tool을 사용해서 총 갯수를 조회해 답변을 생성
## 문제점
하나의 질문, 단순질문에 대해서만 답변할 수 있다.

# V3
## 특징
1. 다중질의(최대 3번)를 처리하기 위해 LLM에게 사용자 질의에 맞는 데이터 조회 코드를 생성
2. 조회 코드를 이용해 데이터 조회
3. LLM 답변
## 문제점
맥락파악을 하지 못한다.

# V4
## 특징
데이터 조회 뿐만 아니라 사용자의 질의 맥락을 파악도 할 수 있다.
