# 청정봇

청년을 위한 맞춤형 정책 안내 및 상담 챗봇 서비스입니다.  
청정봇은 흩어진 청년 정책 정보를 통합하고, 사용자의 조건(나이, 거주지, 소득 등)에 기반한 맞춤형 추천을 제공하며, 자연어 질의를 통해 정책을 직관적으로 안내합니다.

---

## 📌 프로젝트 개요

### 🏛 프로젝트 배경

청년정책 예산은 2021년 23.8조원에서 2025년 28.14조원까지 꾸준히 증가하고 있습니다. 하지만 집행비율은 우하향하여 2024년 기준 총 2.7조원의 예산 집행을 하지 못하였습니다. (나원희, 한국보건사회연구원 사회보장재정데이터연구실 부연구위원)

| 연도 | 청년정책 예산 (조 원) | 전체 정부 예산 (조 원) | 예산 비율 (%) | 집행금액 (조 원) | 집행비율 (%) |
|------|---------------------|---------------------|-------------|---------------|-------------|
| 2021 | 23.8 | 557.9 | 4.27 | 22.1 | 92.9 |
| 2022 | 24.59 | 607.7 | 4.05 | 22.7 | 92.3 |
| 2023 | 25.04 | 638.7 | 3.92 | 23 | 90.6 |
| 2024 | 27 | 656.6 | 4.11 | 24.3 | 90 |
| 2025 | 28.14 | 673.3 | 4.18 | 25 | 89.3 |

*출처: 2025년 청년정책 예산 분석 - 나원희 (한국보건사회연구원)*

### 🧩 문제 인식
- 정책 정보가 여러 기관에 분산되어 접근성 낮음
- 기존 룰베이스 챗봇의 한계: 유연한 대응 불가, 실시간 정보 제공 어려움
- 정보 이해와 신청이 복잡하여 접근 장벽이 존재

### 🎯 핵심 목표
- 사용자 연령, 거주지, 소득 등을 바탕으로 한 **맞춤형 정책 추천**
- **신규 정책 알림** 기능을 통해 최신 정보 제공
- **24시간 대화형 챗봇**으로 실시간 응답
- 정책 예산의 **집행률 제고 및 수요자 중심 예산 활용 유도**

### ✅ 기대 효과
- 정책 정보 탐색 시간 절감 및 만족도 향상
- 미집행 예산을 수요자에게 연결하여 활용도 제고
- 반복 질의 자동화로 **행정 부담 완화**

## 🎯 주요 기능

- **문서 기반 응답**: 정책 문서를 기반으로 RAG 기반으로 사용자의 질문에 정확한 정보 제공
- **맞춤 정책 추천**: 연령, 지역, 소득 등 조건을 바탕으로 개인화된 정책 추천 제공
- **정책 정보 통합**: 다양한 정부/지자체 청년 정책 통합 제공
- **간편 로그인**: 소셜 로그인으로 빠르고 편리하게 서비스 이용 가능
- **히스토리 기능**: 이전 상담 내역을 저장하고 다시 확인할 수 있는 대화 기록 기능 제공

### 1. 사용자 ↔ 웹서비스(실시간 영역)

| 순서 | 구성요소                                          | 역할 / 데이터 흐름                                                                                  |
| -- | --------------------------------------------- | -------------------------------------------------------------------------------------------- |
| ①  | **User (웹·모바일 브라우저)**                         | 정책 관련 질의(query) 전송 / 응답(response) 수신                                                         |
| ②  | **Django (백엔드)**                              | - HTTP API·세션·OAuth(Naver)<br> - WebSocket 실시간 스트림<br> - LangChain 파이프라인 호출                  |
| ③  | **Frontend (HTML 5 · CSS 3 · JS + Tailwind)** | 반응형 UI / 채팅 인터랙션                                                                             |
| ④  | **LangChain**                                 | 1) *사용자 질의 파악* (NLP·LLM)<br> 2) *청년 정책 검색* (SQL 쿼리 to PostgreSQL)<br> 3) *답변 생성* (RAG + 템플릿) |
| ⑤  | **PostgreSQL (RDS)**                          | 구조화된 정책 메타·본문 저장소<br>LangChain의 검색·생성 단계에서 직접 조회                                             |

### 2. 배치 서비스(데이터 수집·ETL 영역)

| 단계 | AWS 서비스       | 폴더/기능                      | 설명                                                      |
| -- | ------------- | -------------------------- | ------------------------------------------------------- |
| A  | **S3**        | `raw/`                     | 외부 정책 원천 데이터를 그대로 적재                                    |
| B  | **Lambda #1** | 청년정책 데이터 수집                | 크롤러/스크래퍼 → `raw/` 업로드                                   |
| C  | **S3**        | `preprocessed/`            | 정형화·정규화된 CSV/JSON                                       |
| D  | **Lambda #2** | 데이터 전처리                    | `raw/` → 파싱·클린징 후 `preprocessed/`                       |
| E  | **S3**        | `policy_reclassification/` | ML 모델 결과(세부 분류)                                         |
| F  | **Lambda #3** | ML 전처리(정책 분류)              | 텍스트 임베딩·카테고리 재분류                                        |
| G  | **Lambda #4** | PostgreSQL 삽입/업데이트         | `preprocessed/`, `policy_reclassification/` → RDS MERGE |
